# 🛍️ Nostra Clothing Website

Nostra is a **responsive clothing website** designed to provide a simple and attractive online shopping experience. The website includes multiple pages for browsing collections, contacting the brand, and managing products in a shopping cart.

## 🌐 Pages

* 🏠 **Home** – Landing page with featured products and offers.
* 🛍️ **Collections** – Browse different clothing collections and products.
* 📞 **Contact** – Contact page with relevant information and a contact form.
* 🛒 **Cart** – Add and manage products in the shopping cart.

## ✨ Features

* Responsive design for different screen sizes
* Modern and clean clothing-store UI
* Product collection section
* Shopping cart functionality
* Easy navigation between pages
* User-friendly layout
* Mobile-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🎯 Purpose

This project was created to practice **frontend web development, responsive design, website navigation, and JavaScript functionality** by building a clothing e-commerce style website.
